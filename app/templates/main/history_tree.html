History Tree workflow
  1. Search for a batch or select one from the quick pick lists.
  2. Review batch details and lineage statistics in the left column.
  3. Use the visualization controls to explore ancestors, descendants, or the full tree.
  4. Fit the view or export the SVG if you need to share the lineage.

Tips

  • Hover a node to see name and cell line. Click a node to jump to its history.
  • The app first tries the optimized v2 API and falls back to the classic lineage endpoint automatically.
  • If the tree looks incomplete, refresh to load a deeper viewport.
